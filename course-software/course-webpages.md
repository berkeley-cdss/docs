# Course Webpages

## GitHub Pages

Many courses use GitHub Pages to deploy their websites. Here's some useful documentation:

- [Pages quickstart](https://docs.github.com/en/pages/quickstart)
  - You should set up your base website at a repository named `org-name.github.io` as described in the linked documentation. Some courses deploy their semesterly website here directly. Others additionally have repositories for each semester. You should set a `robots.txt` file for the base website, not for individual semester websites. Only the root `robots.txt` file is guaranteed to be read.
- [Configuring a custom domain](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site)
